# 欢迎补充数据与批评

《遗忘的边界》是一份开放的理论框架，欢迎补充数据、提出反例、指出推论错误。请按以下任一方式提交。

## 一、可以提交什么

| 类型 | 例子 |
|---|---|
| **数据补充** | 可用于检验附录 E 中某条预言（P1—P12）的数据或实验方案 |
| **反例** | 与书中某条主张不符的现象、数据或文献 |
| **边界修正** | 第 14 章地图中某个理论的安放位置或边界判断有误 |
| **C 级降级** | 指出某条 C 级量级被用得过重（附录 F） |
| **形式化改进** | 附录 A 中某个模型假设可被更弱的假设替换 |
| **设计检验** | 第 17 章 D1—D5 设计原则的工程实验结果 |

## 二、提交方式

1. **Issue**：在仓库 Issues 中按模板提交（勘误 / 数据 / 建议）。
2. **Pull Request**：直接修改 `source/*.html`（正文唯一权威来源）与相应附录，并说明改动对结论的影响。
3. **信件**：1610369302@qq.com。

## 三、提交时的要求

- **每个数值都可追溯**：给出来源链接或文献，并标注质量等级（A／B／C）。
- **说明对结论的影响**：该改动是否改变任何结论的方向或强度。
- **反例请附判据**：如果能说明“在什么观测下这条主张会被推翻”，价值最大。

## 四、承诺

- 收到批评后，若是实质性错误，将在 `versions/CHANGELOG.md` 中记录并公开说明。
- 可证伪登记簿（附录 E）**只追加、不改写**：不会为了自洽而修改已登记的预测。
- 若某条主张被推翻，将把它作为“已落空”明确呈现，而非从正文中悄悄删除。

**最好的理论不是权威的陈述，而是一份开放的邀请。**
