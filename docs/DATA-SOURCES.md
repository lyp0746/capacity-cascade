# 文献与来源

《遗忘的边界》主要是一份理论综合，不依赖专有数据集。本文件说明文献来源、引用规则与可复现性。

## 一、文献类型

| 类型 | 例子 | 在书中的作用 |
|---|---|---|
| 成熟数学理论 | Shannon 信息论、率失真、数据处理不等式 | 形式化骨架（A 级） |
| 机器学习方法 | 注意力、位置编码、Hopfield 网络、检索增强 | 系统分析与设计原则 |
| 认知／神经科学 | 工作记忆、遗忘曲线、系统巩固、睡眠重放 | 人类一侧的原则层级证据 |
| 心理与意识理论 | 全脑工作空间、高阶理论、整合信息理论 | 对照与边界 |
| 哲学 | 忒修斯之船、人格同一性 | 含义章节 |

完整文献见书末附录 C，以及各章末的参考列表。

## 二、引用规则

- 正文引用采用「作者（年份）」或「作者等（年份）」，与章末参考列表对应。
- 本书对某文献的“边界”判断（如第 14 章地图）均为**本书的判断**，非原作者自述。
- 被批判的文献同样会被引用；引用不等于赞同。

## 三、没有使用的数据

本书不引用受保护、非公开或需付费授权的数据集。凡涉及“示意性量级”（质量等级 C）者，均为本书构造或对公开量级的粗略复述，并在句内标注。

## 四、可复现性

- **正文**：`source/*.html` 是唯一权威来源，可被任何人直接阅读与核对。
- **插图**：`analysis/make_figures.py` 与 `analysis/make_cover.py` 生成全部 SVG（确定性，无外部依赖）。
- **校对**：`analysis/audit.py` 自动检查术语一致性、公式编号连续性、表图交叉引用、C 级片段与调试字串。
- **构建**：`bash scripts/build.sh` 生成印刷版与电子阅读版 PDF、EPUB 3、Markdown；`bash scripts/validate.sh` 执行质量门禁。

任何读者都可以据此检验书中的编号、交叉引用与文献一致性。
