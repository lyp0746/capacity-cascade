# 修订说明

## 本版要点

**完成日期：2026-10-14。**

**本版次维护（2026-10-14）：** 封面与版权页对齐系列统一版式（与《错位的时间》《区分的演化》一致）并加入 DOI；修复表格长 token 触发的打印整体缩放。内容主张不变。

**归档 DOI：** [10.5281/zenodo.23323277](https://doi.org/10.5281/zenodo.23323277)（Zenodo）。引用本书请使用该 DOI。

本版是《遗忘的边界》的首次成形版本，包含：

- **六部分、十九章正文**：问题重述与框架限定、信息论基础、三个系统分析、跨尺度机制（梦／潜意识／元认知）、理论地图与批判对话、含义与未来。结构不是照搬模板，而是由论证需要决定：前言中的「系统×尺度矩阵」（表 0.4）给出全书骨架。
- **附录 A—G**：数学补充、理论地图详表、参考文献、术语表、可证伪登记簿、证据与数据缺口清单、面向设计的检查清单。
- **核心主张**：三个系统「同约束而不同构」，由「信息约束下的多尺度自适应」这一母题统合。
- **两套分级**：证据等级 A／B／C 与概念等级 甲／乙／丙，全书逐条标注。
- **关键产出三层**：每章结论分为保底／有条件／推测三层，不把不同强度的话搮在同一标签下。
- **适应模式对照**：表 0.6 直说三个系统受约束的方式不同（被动还是主动），以防止“强行类比”的指控。
- **可证伪登记簿**：12 条可检验预言，含指标、判据、时点与混杂因素（附录 E）。
- **理论地图**：二十余个既有理论在三轴（结构／动力学／协调）上的安放与边界（第 14 章、附录 B）。
- **术语类型标记**：标准／调整／造语／隐喻，并给出易混词的辨析（附录 D.2）。
- **理论生命周期表**：从 Ebbinghaus 到 2023 年的理论各自“今天还剩多少有效”（附录 C.4）。
- **设计原则**：D1—D5 五条可反驳的设计主张（第 17 章、附录 G）。
- **结论粒度**：表 0.1 的每个条目只含一个主张，把“现象存在”与“机制归属”分开标注（如位置偏差③④⑤分列）。
- **承重假设表**：第 2.6 节（表 2.3）列出 H1—H6 及其支持度与“若被推翻”的影响面。
- **数据呈现规则**：第 3.2 节明确 A/B/C 各自进正文还是附录，C 级不给具体数字。
- **跨系统映射**：第 8.2 节（表 8.1）给出 LLM 与智能体的概念对应强度。
- **概念辨析**：定义 5.3 区分“表示坍塌／压缩／遗忘”；第 6.2 节警告“时间尺度分离是近似而非严格解耦”；第 5.2 节讨论“如何在三系统中测量 <i>C</i><sub>eff</sub>”。
- **证据—反驳并行**：表 12.2（意识投影论的支持与反对）、表 11.2（梦的四种假说）。
- **思想实验与对话**：第 9.3 节“如果人类有无限工作记忆”；第 2.4、第 12.3 节“如果你反对这一点”。
- **章际过渡**：每章小结后交代“下一章为什么”。
- **逻辑抽检**：第 3.8 节对 5 个论证（3 个关键 + 2 个脆弱）逐条前提→推理→反驳→评分。
- **A 级来源抽检**：附录 C.5 检查“引用是否直接支撑断言”，并把“完整外部文献核验”列为登记缺口。
- **形式化承诺**：附录 C.6 分模块声明哪些形式化、哪些不形式化。
- **可测性表**：表 5.1 给出 <i>C</i><sub>eff</sub> 在三个系统中的可测量性。
- **深思题**：第 11.1、12.1 节（“四个假说是竞争还是分工”）。
- **可实用性（附录 G）**：适用范围表（能／部分／不能解释）、五步诊断工作表（含“先写失败条件”）、两个应用示例（一正一反）。
