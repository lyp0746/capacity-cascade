# 证据与数据缺口清单

本清单汇总《遗忘的边界》全书的 C 级陈述、示意性量级，以及需要外部数据才能检验的判断。它是本书诚实性的检验面。

## 一、C 级示意量级

| 位置 | 陈述 | 为什么是 C 级 |
|---|---|---|
| 第 5.5 节 | 容量—干扰指数模型的形式 | 依赖泊松型占用假设 |
| 第 6.3 节 | 三时间尺度的特征时间常数 | 量级示意，个体与物种差异大 |
| 第 7.3 节 | 有效容量 ≈ d·log(n) | 启发式估计 |
| 第 8.3 节 | 临界轮次 n_c 的两种标度 | 依赖独立同分布假设 |
| 第 9.2 节 | 突触容量 3—5 bit、全脑 10^16 bit | 估计区间宽，争议大 |
| 第 11.2 节 | 内源模拟的最大熵形式 | 形式化假设，未经验证 |
| 第 12.4 节 | 浮现概率 ∝ 相关性 × 显著性 | 启发式 |
| 第 16.6 节 | 显著性是否可还原为信息论量 | 开放问题 |

## 二、需要外部数据才能检验的判断

| 缺口 | 所需数据 | 难点 |
|---|---|---|
| 位置偏差的机制归属 | 多模型、多编码方案的注意力与准确度曲线 | 需访问模型内部状态 |
| 干扰强度的统一操作定义 | 三系统一致的“干扰”度量 | 跨系统度量尚不存在 |
| 智能体漂移的标度 | 受控对话中的状态距离序列 | 度量未标准化 |
| 人类突触容量的可靠估计 | 突触状态数与可读性数据 | 技术与伦理限制 |
| 梦的功能的直接干预 | 对离线重组的选择性干预实验 | 人类难实施 |
| 离线重组在人工系统中的收益 | 大规模训练＋重组对照实验 | 算力成本 |
| 时间常数的第一原理推导 | 生物物理参数与跨物种比较 | 跨学科理论工作 |
| 显著性是否可还原 | 显著性对信息论量的可解释比例 | 需大规模交叉研究 |
