# 方法论

《容量级联》不是实证研究报告，也不是纯哲学著作。它是一份**理论综合与假说框架**。本文件说明它的方法论规则，供读者与审稿人核对。

## 一、两类等级（正交）

| 证据等级 | 含义 | 操作判据 |
|---|---|---|
| A | 官方可复现／成熟定理 | 存在公开可复现路径；结论不依赖本书构造 |
| B | 稳定公开估计／稳健观察 | 多来源一致或跨样本稳健，但有口径不确定性 |
| C | 稀疏／构造／思辨 | 单一来源、示意量级或纯推演；仅用于方向 |

| 概念等级 | 含义 | 操作判据 |
|---|---|---|
| 甲 | 形式化且可检验 | 有明确定义，能导出可判定预言 |
| 乙 | 有框架，暂无独立判定 | 有形式化表述，但依赖未定参数 |
| 丙 | 启发式类比／思辨 | 无形式化，或形式化仅为装饰 |

二者**互不决定**：经验强不等于形式化强，反之亦然。

## 二、四类断言标记

- **［已知］**：有 A 或 B 级经验支持，可作为进一步推理的前提。
- **［论证］**：在明示假设下的推理，结论随假设成立（条件性，不自动为真）。
- **［假说］**：有间接证据但未被独立检验的机制主张；作为研究起点，不作为前提。
- **［待验证］**：已登记判据与时点、尚无结果的预言。

## 三、可证伪登记制度

凡提出可检验预言，必须同时登记五元组：**(P)** 预言陈述；**(m)** 指标；**(θ)** 成功／失败判据；**(t)** 计划核对时点；**(c)** 混杂因素。缺少任一项，不构成可检验命题。登记簿（附录 E）**只追加、不改写**。

## 四、写作纪律

1. **每个数带等级**；C 级绝不伪装成 A 级。
2. **反例进正文**，不被弱化为脚注。
3. **不用版本化的自我叙事**；只呈现最终论证。
4. **地图只定性，不定量**；统计与数值留给方法章节与附录。
5. **区分现象与机制**；不因现象稳健就宣称机制已定。

## 五、本书明确不做的事

- 不做数值预测。
- 不做临床或工程建议（第 17 章为设计假说）。
- 不做哲学定论（第 18 章给立场，不给结论）。
- 不隐藏与主张不符的证据。

## 六、复现方式

- 正文唯一来源为 `source/*.html`；结构与目录见 `source/parts.json`。
- 插图与封面由 `analysis/make_figures.py`、`analysis/make_cover.py` 确定性生成。
- 校对由 `analysis/audit.py` 自动完成，输出 `校对清单.md` 与 `analysis/results/audit.json`。
- 完整构建见 `bash scripts/build.sh`。
