附录 A　数学补充

本附录汇总正文中使用的形式化定义与推导，供希望核对细节的读者查阅。所有公式均沿用正文的符号约定（表 0.5）。

A.1　信息瓶颈与率失真

信息瓶颈的拉格朗日形式：

LIB[p(z|x)] = I(X;Z) + β I(Z;Y)(A.1)

其中 β ≥ 0。当 β → 0 时最优解为 Z ≈ X（无损）；当 β → ∞ 时 Z 退化为常数（零信息）。信息曲线 (I(X;Z), I(Z;Y)) 是一条凸曲线。

率失真函数（式 4.2）与其对偶：

R(D) = min_{p(x̂|x): E[d] ≤ D} I(X;X̂)　⟺　D(C) = min_{I ≤ C} E[d](A.2)

对高斯信源与平方失真，R(D) = ½ log2(σ2/D)（D ≤ σ2）。这是本书能给出的少数精确闭式之一。

A.2　数据处理不等式

X → Z → Y　⟹　I(X;Y) ≤ I(X;Z)(A.3)

推论：若 Z 是 X 的确定性函数，则 H(Z) ≤ H(X)，且一般严格小于。信息不会因处理而增加。

A.3　有效容量的熵形式

给定可区分状态概率分布 {pi}，有效容量定义为该分布的 Shannon 熵：

Ceff = −Σi pi log2 pi　（式 5.1 的定义）(A.4)

当状态等概率且数目为 N 时，Ceff = log2 N，即名义容量。

A.4　有效秩（参与熵）

rankeff(M) = exp( −Σi pi ln pi )，　pi = σi2/Σj σj2(A.5)

性质：rankeff ≤ rank(M) ≤ min(n,d)；等号成立当且仅当谱平坦。它在比例缩放下不变。

A.5　容量—干扰模型的推导

设干扰 ι 使表示中可用方向的数目按每单位干扰以速率 k 被占用（泊松型假设），则未被占用的比例约为 e−kι。加上结构本身提供的“保底容量” C∞：

Ceff(ι) = C∞ + (Cmax − C∞) e−kι(A.6)

半衰点：Ceff 降到中值处，ι1/2 = ln 2 / k。低干扰展开：Ceff ≈ Cmax − (Cmax−C∞)kι + O(ι2)。该推导依赖泊松型占用假设，因此是条件性结果（等级 C）。

A.6　目标漂移的标度

设每轮偏移 εi = μ + ξi，其中 μ 为偏置、ξi 为零均值独立噪声，Var(ξ) = σ2。累积位移 Sn = Σi≤n εi 的均值与方差为：

E[Sn] = nμ，　Var(Sn) = nσ2，　E[‖Sn‖2] = n2μ2 + nσ2(A.7)

因此：当偏置占优（nμ2 ≫ σ2）时，位移随 n 线性增长；当噪声占优时，随 √n 增长。临界轮次分别为 nc ≈ r/μ 与 nc ≈ r2/σ2（r 为盆半径）。正文式(8.5)即此。

A.7　总数据不等式（多级）

对 Markov 链 X → Z1 → Z2 → … → Y：I(X;Y) ≤ I(X;Z1) ≤ …。级联的每一层都在做信息上的“只减不增”操作，这为第 6 章的“丢弃是层间唯一传送带”提供了严格基础。

A.8　形式化的边界

本附录中的所有公式，都是在明示假设下的条件性结果。它们不构成对任何具体系统的直接预测。特别是：

  • 式(A.6)的 k、C∞ 不能先验给出；
  • 式(A.7)假设偏移独立同分布，而真实系统中的偏移往往相关；
  • 互信息在高维连续情形下难以精确估计，本书只用其方向与相对大小。
