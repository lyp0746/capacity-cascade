第20章　记忆的训练与迁移

学会骑车之后，学摩托快得多。可学会游泳之后，学冲浪并没有快多少。迁移不是自动的，它要看两件事像在哪里。

"记忆能练吗？"这是最常被问、也最容易被夸大回答的问题。本章用容量级联的框架，把"能练什么、不能练什么"分开。

20.1　三种"记忆训练"

第一种：策略训练。教人用"记忆宫殿""组块""联想"等策略。这类训练的效果最稳定——因为它改变的是"压缩方式"，不是"原始容量"。

第二种：任务训练。反复练某一个具体任务（如记数字）。效果局限于该任务，迁移很弱。

第三种：核心训练。声称能提高"工作记忆容量"本身。争议最大。

20.2　为什么"策略"有效，"核心"可疑

容量级联的读法是：容量是"预算"，策略是"怎么花预算"。策略训练教你"把信息压成更大的组块"，于是同样的预算能装更多——这是"压缩"的胜利。

而"核心训练"声称能"提高预算本身"。但预算受生理约束，很难通过短期训练改变。这就是为什么"核心训练"的迁移效果一直有争议。

20.3　"专家优势"的启示

专家不是"容量更大"，而是"压缩更好"。棋手能记住整盘棋，但记不住随机摆的棋子——因为前者有结构，后者没有。

这给"记忆训练"一个明确的启示：与其练"容量"，不如练"结构"。

20.4　迁移的边界

"迁移"分两种：

  • 近迁移：同一领域内的迁移（如记数字→记电话号码）；
  • 远迁移：跨领域的迁移（如记数字→记单词）。

近迁移较可靠，远迁移很弱。所以，"练记忆能变聪明"这个说法，大多站不住。

20.5　一个可做的练习

选两组词：一组有结构（如"猫、狗、鸟"），一组无结构（如"猫、桌子、蓝色"）。各记 10 个，测回忆。

你会发现：有结构的那组，记得更多。这不是"容量变大"，而是"压缩变好"。

20.6　本章的边界

本章的结论是"策略优于核心训练"，这是B 级判断；"容量不可训练"是C 级——因为"容量"本身很难定义。

20.7　“记忆比赛”选手的记忆法

记忆比赛的选手，能在几分钟内记住一副扑克牌的顺序。他们靠的不是“天赋”，而是“技术”：

  • 记忆宫殿：把要记的东西，挂到熟悉的空间上；
  • 编码：把抽象信息（数字、牌）变成具体图像；
  • 故事：把图像串成一个荒诞的故事。

用容量级联读。这三件事，都是“压缩”：把“无结构的信息”，压成“有结构的故事”。容量没变，但“每个组块”装得更多了。

20.8　“记忆训练”的迁移边界

记忆比赛的冠军，在“记牌”上很强，但在“记单词”“记人脸”上，可能并不比普通人强。

为什么？因为“记忆宫殿”是“特定任务的策略”，不是“通用容量”。迁移，发生在“同类结构”上，不发生在“所有任务”上。

这就是“策略训练”的边界：它教你“怎么压”，不教你“压什么”。

20.9　间隔重复的“最优间隔”，一个可算的玩具模型

“间隔重复有效”是共识，但“间隔该多长”常被当成经验。这一节给一个极简模型，让这件事可以被算出来——并且明确标出它只是模型。

假设。 记忆强度按 R(t)=exp(−t/S) 衰减；每次在 R 降到阈值 θ 时复习，复习成功后 S 乘以 k。于是第 i 次复习的间隔是 Δᵢ = −S·ln θ，且 S 每次乘 k。

取 θ=0.9、S₀=1（天），算“维持一年”所需的复习次数：

复习增益 k一年所需复习次数前六个间隔（天）
1.2360.1 / 0.1 / 0.2 / 0.2 / 0.2 / 0.3
1.5190.1 / 0.2 / 0.2 / 0.4 / 0.5 / 0.8
2.0120.1 / 0.2 / 0.4 / 0.8 / 1.7 / 3.4
3.090.1 / 0.3 / 0.9 / 2.8 / 8.5 / 25.6

读法一：复习次数对“每次增益”极其敏感。 k 从 1.2 提到 2.0，复习次数从 36 降到 12——三倍差距。这意味着：“怎么复习”比“复习多少次”更重要。如果一次复习只是重读，k 接近 1，你就要复习三十几次；如果是主动回忆 + 间隔，k 会大得多。

读法二：间隔是“指数拉开”的，不是“均匀”的。 k=2 时，前六个间隔是 0.1、0.2、0.4、0.8、1.7、3.4 天——每一步大约是前一步的两倍。这与“每天复习一点”的直觉相反：均匀间隔会浪费大量时间在已经牢固的内容上。

读法三：这个模型一定是错的。 真实记忆不是单指数，S 的增益也不是常数，还有干扰、情绪、睡眠的影响。但它的用途不在预测，而在给出“数量级”： 你可能只需要十几次复习，而不是一百次；间隔应该拉开，而不是均匀。

【给专家的注】这个模型与间隔重复软件（如 SM-2 系列）的思路同源：以“回忆成功率”为控制变量，动态拉长间隔。差别在于真实系统需要为每个条目估计 S 与 k，而本书只用它来说明“为什么间隔要拉开”。等级：C（说明性模型）。

人的尺度

一个学生背单词，一天五十个，第二天剩二十个。他以为自己在失败。后来改成一天二十个、隔天复习，第二天剩十八个：总数少了，留下来的多了。训练与迁移的差别就在这：前者让你今天有成就感，后者让你三个月后还能用。

20.10　与语言习得的连接：关键期是一种容量调度，不是一堵墙

语言习得里最常被误读的一件事是"关键期"。流行的说法是"过了十二岁就学不会母语了"，但实验证据要保守得多：语法辨音的敏感度在青春期后下降，而词汇与语用几乎不设限。这不是一堵墙，是不同子系统的时间表不同。

用本书的容量框架读，关键期是"容量分配的窗口"：早期大脑把大量资源投给语音与句法（因为这两项的数据在那时最密集），后期资源转向语义与语用。窗口关闭不是能力消失，是资源被重新分配——这与第 6 章"多时间尺度级联"是同一条：级联的每一级有自己的时间常数。

断言 20.4（B 级，发展语言学） 关键期的"关闭"应表现为同一任务的资源竞争加剧（学新语音时旧语音的保持率下降），而非绝对能力的消失；若观察到"无竞争的能力消失"，本节读法需修正。

它在哪里会失败。资源竞争很难直接测：你无法给人脑做一次容量审计。所有证据都是行为的（学习速度、保持率），而行为证据会被动机与输入量混淆。这是本节只能给方向的原因。

它使什么成为可能。它给成人学习一个不那么悲观的结论：不是学不会，是要挤占。挤占的策略（先学高价值、接受旧技能的衰退）比"抓紧关键期"更实际。

本章小结
  • 训练与迁移是两件事：前者提高当期表现，后者改变长期可用性。
  • "策略"类训练有效，"核心容量"类训练可疑。
  • 专家优势的启示是：可迁移的是结构，不是容量本身。

一句话带走：训练让你今天有成就感，迁移让你三个月后还能用——这两件事经常相反。
