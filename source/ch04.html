第 4 章　信息瓶颈与率失真：压缩—相关性权衡

从本章起，本书进入“母题”的形式化。我们要把“容量有限，所以要压缩，所以会遗忘”这句直觉，升级为一个可以写出来、可以讨论其假设、也可以被批判的优化问题。本章给出两个成熟工具——信息瓶颈（information bottleneck, IB）与率失真理论（rate–distortion theory）——并说明它们各自能做什么、不能做什么。本章的骨架是 A 级（成熟数学）；一旦把它套到具体系统上，等级就会下坠——而每一处下坠，都是一个可以拿去实验的问题。

4.1　导论：为什么从一个优化问题开始

描述“遗忘”有两种方式：现象学的（画一条遗忘曲线）与目的论的（说清系统在优化什么）。前者容易测量，但不解释机制；后者解释了机制，却常被滥用——只要说“系统在最小化某个量”，似乎一切都能解释。本书采取折中：先写清楚优化问题与它的假设条件，再说明它预测什么、不预测什么。这样，即使读者不接受“系统真的在优化它”，也可以使用它作为规范性基准（normative baseline）：真实系统与这个基准的差距，本身就是信息。

定义 4.1　规范性基准 若一个优化问题的最优解刻画了“在给定约束下信息最多能怎样被保留”，则称它为规范性基准。规范性基准不假设系统真的求解了该问题；它提供一个上界或下界，用于度量真实系统偏离最优的程度。

4.2　信息瓶颈的规范陈述

给定输入 X、任务目标 Y，以及由 X 产生的内部表示 Z（由条件分布 p(z|x) 决定），信息瓶颈求解：

minp(z|x)　LIB = I(X;Z) + β · I(Z;Y)(4.1)

这里 β ≥ 0 是压缩强度参数。围绕式(4.1)有三个必须说清的要点。

第一，符号约定。不同的表述中 β 的方向相反：有的写成 max [I(Z;Y) − β−1I(X;Z)]。本书统一采用式(4.1)的写法：β 越大，压缩越强。凡引用文献时方向相反者，本书在引用处换算，不再重复说明。

第二，它是一个变分问题。被优化的是编码分布 p(z|x)，不是 Z 的取值。这很重要：它意味着瓶颈描述的是“如何选择表示”，而不是“表示的内容”。

第三，它有一个变分下界。当 p(z|x) 被参数化（例如神经网络）时，可以用变分推断近似求解；此时出现一个可调的温度参数，与 β 相关。这是 IB 能被经验使用的原因，也是它引入额外假设的原因。

定义 4.2　有效压缩率 在给定 β 下，定义有效压缩率 R(β) := I(X;Z) 与有效相关性 Q(β) := I(Z;Y)。二者随 β 的关系曲线称为信息曲线（information curve）。信息曲线是本书后文比较系统的基本曲线。

4.3　拟合—临界—压缩三相位

在训练动力学中，一个被反复报告的现象是：学习并非单调地“先记后忘”，而是经历一个可辨识的三阶段结构——先拟合数据，再经过一个临界区，然后进入压缩。Saxe 等（2018）与 Shwartz-Ziv 与 Tishby（2017）报告了这一现象。［已知，B／乙］

图 4.1　信息曲线与三相位。横轴为压缩（I(X;Z) 下降方向向右），纵轴为任务相关性 I(Z;Y)。曲线先上升（拟合相位，表示获得与任务相关的结构），经过一个临界区（曲线趋于平缓，此时压缩开始主导），最后轻微下降或稳定（压缩相位，与任务无关的信息被丢弃）。关键限定：三相位是否普遍存在仍有争议；它在某些架构与任务上清晰，在另一些上不明显。图中曲线为定性示意，非实测。
警告 4.3.1　三相位不是“学习的三个哲学阶段” 坊间常把三相位直接说成“学习—理解—融会贯通”，这是一种过度解释。三相位是在特定参数化与训练设置下观察到的信息曲线的形状，它不自动等于认知意义上的理解。本书只在“信息曲线的形状”这一严格含义下使用该概念。

4.4　率失真理论：有限容量下的最优失真

信息瓶颈处理“任务相关”的压缩；率失真处理“在给定失真度量下”的压缩。给定信源 X、失真函数 d(x,x̂) 与允许的失真 D，率失真函数 R(D) 定义为：

R(D) = minp(x̂|x) : E[d(x,x̂)] ≤ D　I(X;X̂)(4.2)

R(D) 是在给定失真约束下，重建信源所需的最少信息量。它的对偶形式（容量—失真）说：若通道容量为 C，则可达到的最小失真是 D(C)。这条对偶是本书区分“容量不足”与“选择不当”的工具。

4.5　数据的处理不等式与不可逆性

信息论约束之所以“硬”，核心是数据处理不等式（data processing inequality, DPI）：

X → Z → Y　⟹　I(X;Y) ≤ I(X;Z)(4.3)

它的含义是：对数据做任何（可能是随机的）处理后，关于原始量的信息不会增加。这是本书“遗忘不可逆”的数学来源，也是整本书最硬的一块砖：

定义 4.3　信息论意义上的不可逆 若从 X 到 Z 的处理丢失了 I(X;Z) < H(X) 的信息，则不存在仅依赖 Z 的后续处理能把丢失的信息完全恢复。称这种丢失为信息论意义上的不可逆。

注意限定词：“仅依赖 Z”。如果系统还保有别的信息源（如原始 X 的另一份副本、外部存储、或任务先验），则实际可恢复性可能提高。这正是工程上“外部记忆”“检索增强”之所以有效的原理：它们不是逆转了遗忘，而是绕开了被压缩的那条通道。

4.6　三种“遗忘”的区分

“遗忘”在日常语言中是一个词，在机制上至少是三种东西。把它们混为一谈，会导致错误的诊断与错误的干预。

表 4.2　三种遗忘的机制、信息论表述与可干预方式
类型机制信息论表述可干预方式
消退（decay）表示随时间自然减弱I(X;Z; t) 随 t 下降复习／重放；提高稳定性
干扰（interference）新信息与旧信息竞争资源I(Xold;Z | Xnew) 下降隔离通道；选择性重放
检索失败（retrieval failure）信息仍在，但当前线索无法取用I(线索;Z) 下降，但 I(X;Z) 未必下降改变线索；提供上下文
性质：机制区分表。质量等级 B（心理学中三者有大量研究支持）；注释：三种机制在实践中常同时发生，难以完全分离。“检索失败”这一项对工程尤其重要：它意味着“模型表现下降”未必等于“信息已丢失”。

这张表解释了本书为什么在第 8 章要区分“漂移”与“遗忘”：它们对应不同的机制类别，也对应不同的干预。把检索失败误诊为容量不足，会导致错误的“扩容”投资。

4.7　信息瓶颈的适用边界

信度要求我们写出 IB 在本书中的四条边界。

  1. 互信息难估。高维连续变量的互信息估计本身有偏、方差大。本书因此只在相对比较（谁比谁更压缩）与方向判断（压缩增强会怎样）上使用 IB，不用它给出绝对 bit 数。
  2. 任务相关性不是固定目标。标准 IB 假设 Y 给定。但真实系统的“任务”常由奖励或演化塑造（第 15.4 节），且随时间变化。固定 Y 是一个近似。
  3. IB 不含时间。它描述一个静态的最优编码，不给出“为什么遗忘需要 τ 秒”。时间常数必须从别处引入（第 6 章）。
  4. IB 不解释内源计算。当没有外部输入时（X 为空），I(X;Z) 无意义。梦与内源模拟因此落在 IB 之外（第 10—11 章）。
本章的关键产出（保底／有条件／推测）
  • 保底（可直接使用）：IB 与率失真是成熟数学；DPI 与不可逆性是可用的硬约束。［已知，A／甲］
  • 有条件（可直接使用）：“三相位”是常见现象但非普遍；本书只在信息曲线形状的意义上使用。［已知，B／乙，有条件］
  • 推测（尚不可用）：把 IB 的绝对数值用于具体系统，本书不做，也不建议。［边界］

本章小结

  1. 信息瓶颈把“压缩—相关性”写成式(4.1)的变分问题；率失真给出容量—失真的对偶下界。
  2. 数据处理不等式使“信息不回增”，因此压缩掉的损耗不会自己回来——但绕开通道（外部记忆、检索、先验）是一条真实的路。
  3. 遗忘至少分消退、干扰、检索失败三类；混淆它们会导致错误干预。
  4. IB 的边界：互信息难估、任务常不固定、不含时间、不解释内源计算。这些缺口正是后续章节的接口。

压缩的规范性基准已经齐备。但“容量”本身仍然是一个笼统的词；第 5 章把它与“干扰”一起变成可测的量，并给出全书最容易被实验检验的模型。
