## 编号顺移的校验口径

`renumber.py` 之后另跑两次校验，避免双重平移：

1. `<h3>` 内文的首个编号没有被第一遍覆盖 → 单独修了一遍（只改 h3 内文，不改 `sec` id）。
2. `parts.json` 的 `sections` 改为**从 HTML 重新抽取**，不再独立平移——这是唯一不会漂的做法。

最终校验（三者必须全绿）：

- 每个 `chNN.html` 的 `<h2>` 章号 == `parts.json` 的 `no`
- 每个 `<h3>` 文本 == `parts.json` 的 `sections[i]`
- 每个 `id="secNN-M"` 的 NN == 文件名章号
- 全书 `第 N.M 节` 引用都能在 `parts.json` 里找到对应小节（悬空引用 0）

## 不要重跑 renumber.py

它是一次性的。再跑一次会把 12—25 再平移一档。若要回滚，用 `git revert` 到 `检查点：重构前` 那个提交。
