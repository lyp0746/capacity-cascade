# 版本脉络（内部）

> 本文件为仓库内部记录，**不随发布包分发**，也不得把版本号写入正文、元数据或封面。
> 读者可见的版次信息以真实完成日期为准（见 `source/book.json`）。

## 首版（完成日期 2026-10-12）

**定位**：理论专著与假说框架。核心主张——大语言模型的键值缓存、AI 智能体的上下文窗口、人类的记忆—学习系统，**同约束而不同构**；由“信息约束下的多尺度自适应”母题统合。

**结构**：六部分、十九章；附录 A—G。

- 第一部分 问题的重述与框架的限定（第 1—3 章）
- 第二部分 信息论基础：容量、干扰与时间（第 4—6 章）
- 第三部分 三个系统的分析（第 7—9 章）
- 第四部分 跨越尺度的机制：梦、潜意识与元认知（第 10—13 章）
- 第五部分 理论地图与批判对话（第 14—16 章）
- 第六部分 含义、局限与未来（第 17—19 章）
- 附录 A 数学补充；B 理论地图详表；C 参考文献；D 术语表；E 可证伪登记簿；F 证据与数据缺口清单；G 面向设计的检查清单

**方法**：

- 两套正交等级：证据 A/B/C，概念 甲/乙/丙。
- 四类断言标记：［已知］／［论证］／［假说］／［待验证］。
- 可证伪登记簿（附录 E）：P1—P12，含指标、判据、时点、混杂因素。
- 理论地图（第 14 章、附录 B）：二十余个理论在三轴上的安放与边界。

**写作风格**：张力优先、避免宿命论；分级在装置而非每句；反例进正文；地图只定性。风格规范同步写入 skill `academic-book-pipeline/references/voice.md`。

**工程**：

- 正文唯一来源 `source/*.html`；插图与封面确定性生成（`analysis/make_figures.py`、`analysis/make_cover.py`）。
- 校对脚本 `analysis/audit.py`；构建 `scripts/build.sh`；发布 `scripts/release.sh`。
- 发布采用**一个产物一个 tag**：`scripts/create_github_release.py` 为每个产物各建一个 tag 与 release。
